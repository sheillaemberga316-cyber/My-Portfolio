# My Professional Portfolio Website

Personal portfolio website created to showcase my background, skills, education, experience, and digital projects as an IT student.

## 🚀 Live Demo
You can view the live website hosted online:
👉 [https://sheillaemberga316-cyber.github.io/My-Portfolio/](https://sheillaemberga316-cyber.github.io/My-Portfolio/)

## 🛠️ Built With
* HTML5 / CSS3 / JavaScript
* Tailwind CSS / Modern UI Design
* Responsive Grid & Flexbox Layouts
* Hosted on GitHub Pages

## 📂 Project Structure
- `index.html` - Main Landing / Home page
- `projects/` - Digital projects and project details pages
- `assets/` - Images, profile photos, and CV PDF file
- `styles/` - Custom CSS styling and dark mode configurations
